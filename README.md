This project is currently used as a **learning and practice ground for CI/CD and modern frontend workflows**.

## 🔄 CI/CD Pipeline

This project implements a **CI/CD pipeline using GitHub Actions**, added as part of my continuous learning process.

### Pipeline Workflow
The pipeline runs automatically on:
- `push` to the `main` branch
- `pull_request` targeting `main`

### Pipeline Steps
- Install dependencies (`npm install`)
- Run ESLint for code quality validation (`npm run lint`)
- Build the React application (`npm run build`)
- Deploy to **GitHub Pages** if all previous steps succeed

### Benefits
- Ensures code quality before deployment
- Prevents broken builds from being deployed
- Automates deployment process
- Simulates real-world CI/CD workflows used in production environments
