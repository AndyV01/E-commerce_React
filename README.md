## ⚙️ CI/CD

Este proyecto incluye pipeline de **Integración Continua y Despliegue Continuo** con GitHub Actions.

**Workflow principal:** `.github/workflows/ci-cd.yml`

### ¿Cuándo corre?
- Push a rama `main`
- Pull Request hacia `main`

### Etapas automatizadas
1. Instalación de dependencias (`npm install`)
2. Linting (`npm run lint`)
3. Build de producción (`npm run build`)
4. Deploy automático (GitHub Pages)
